# African Caribbean Cuisine — website

Website for African Caribbean Cuisine in Palestine, Texas: Cameroonian, West African and Caribbean food, with dine-in, takeout, call-ahead, catering and delivery.

Static site, no build step: `index.html`, `styles.css`, `script.js`, `menu.js`, and `images/`. Deploy the folder as-is on Vercel.

## Things to fill in
- **Phone, street address, catering email:** top of `script.js` (`BUSINESS`). The call buttons, map and catering form update automatically.
- **Menu and prices:** `menu.js`. All prices are placeholders until confirmed.
- **Logo:** `images/logo.svg` is a placeholder. Replace it with the real logo (same name), or tell us the new file name.
