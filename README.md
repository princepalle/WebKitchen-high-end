# WebKitchen — high-end websites for restaurants & kitchens

- `/` — the WebKitchen studio site (`index.html`, `studio.css`, `studio.js`). Add your contact email or phone at the top of `studio.js` to turn on the "Start a project" buttons.
- `/demo/african-caribbean/` — showcase: a premium site for African Caribbean Cuisine (Palestine, TX). Menu in `menu.js`, phone/address at the top of `demo.js`. Prices are samples.

Static site, no build step. On Vercel: import the repo, framework "Other", deploy.
